## RTL 缺陷证据链（结构判定法）

| 实验 | 观测 | 推论 |
|---|---|---|
| 512 点单音 bin5 | 峰 {5, 507, **251, 261**} | = even/odd 各自 256-FFT 交错 |
| 4096 点单音 bin5 | 峰 {5, 4091, **2043, 2053**} | = 双 2048-FFT——**通用缺陷，非部分趟特有** |
| 直流 5000 | 峰 {0, **256**} 各 2496 | 双半 DC ✓ 同上 |
| 脉冲 | 平坦 58≈30000/512 | 变换核心构件正确，纯 1/N 缩放 |
| 增益拟合 | 0.5×1/N | 多执行一次 ÷2 |
| **库真值对照** | 真 512-FFT（vs 理想 max\|Δ\|=2.67） | **库=正确行为；现 RTL 与参考不符** |
| C-fl 模型 | vs 理想 -108dB | 模型=真 512 FFT（bit-exact golden 依旧成立） |

**判定**：合并趟（第 3 趟/pipeline2）未生效——输出等效于"分流+双半 FFT"，且整体多一次 ÷2。
高度怀疑：`fft_control` 的 `mdc_stage_reg` 译码（mdc_left_stage>3 → 0000 → 取 switch[3]）
或趟3 输出路由/写使能；每趟末级多做了一次 ÷2 蝶形而无合并效果。

## 根因进展（2026-10-22 追加）

- 趟调度验证**无误**：512 = 2 中间趟 + 1 输出趟（left_stage 8→4→0），末趟抽头 0001 正确——与"按点数配置"无关（用户猜想已排除：4096 全趟配置同缺陷）
- 末趟 W 旋转因子**正确**（W^k_512 全周扫描，与模型 dim-8 公式细算一致）
- **冒烟枪：末趟 X2 支路恒为 (0,0)** → 蝶形退化为 y=X1/2（多一次÷2、无合并）——100% 吻合全部观测
- 缺陷定位：末趟第二个输入支路的数据源（fft_array RAM 读地址 / pe2ramin lane 写入）——下一步从这里挖

## 当前精确定位（未解）

缺陷 = **array_sort_ram 的 8 并行度流式转置方程错误**：
- 写使能/写地址/趟调度/计算值全部正确（bank2 中 256 个非零值 100% 命中模型期望）
- 唯独 fft_core_o 在 flush 的半数拍输出零（30/61 实测）
- 根源：重构从 2 并行度（旧版按其设计）迁到 8 并行度时，缓冲容量=半帧，
  写（线性+半区翻转）与读（cnt[1:0] 旋转）方程不构成互逆
